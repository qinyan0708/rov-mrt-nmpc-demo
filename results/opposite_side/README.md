# Opposite-side reference run

These files were extracted from ROS 2 bag
`opposite_side_20260912_190205`, recorded on 2026-09-12.

- `diagnostics.csv`: 226 NMPC diagnostic samples.
- `state.csv`: 228 vehicle-state samples.
- `control.csv`: 228 applied-control samples.
- `summary.json`: metrics recomputed from the three CSV files.
- `overview.png`: generated by `tools/plot_results.py`.

The raw 10.2 MiB MCAP bag is intentionally omitted to keep the repository
small. The README provides the exact topics needed to record a new bag.
